Overview

Being successful as a computer science major at Penn State takes more than just passing classes. Students need to build strong problem-solving ability, understand technical concepts deeply, and stay consistent with practice outside the classroom. Online resources can help fill in gaps, reinforce difficult topics, and provide extra opportunities to grow.

This website focuses on six online resources that can help Penn State computer science students improve: LeetCode, Abdul Bari's YouTube channel, Coursera, GeeksforGeeks, Reddit, and GitHub. Each one supports a different part of the learning process. LeetCode helps with coding interview preparation and algorithmic thinking. Abdul Bari helps explain difficult concepts clearly. Coursera offers structured courses that can strengthen technical foundations and introduce new topics.

What’s in this Guide

This guide includes multiple online resources that support coding practice, concept learning, course planning, interview preparation, and project development. Each page explains what the resource is, how it helps Penn State students, and provides a direct link for easy access.

Who this Guide is For

This guide is designed for Penn State computer science students at any level. It can help newer students understand difficult topics, while also helping more experienced students prepare for internships, technical interviews, and personal projects.

What this Guide Assumes

The guide assumes that students may already have some basic programming knowledge, but may still need support with algorithms, data structures, electives, or building a stronger portfolio.

How to Use this Guide

Use the navigation bar at the top to explore each resource. Each page focuses on a different tool that supports a specific part of the computer science learning process.

Why these resources matter

Penn State CS students often balance programming assignments, theory-heavy classes, projects, and internship preparation. Using outside resources can make it easier to review concepts, practice consistently, and build confidence over time.

Tips for Using the Guide

A good strategy is to combine resources depending on your needs. Use LeetCode and GeeksforGeeks for practice, Abdul Bari and Coursera for learning concepts, Reddit for advice from other students, and GitHub to showcase your projects.
